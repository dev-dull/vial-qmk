## Important note about this archived fork of `vial-qmk`:
This repo contains alternate firmware for the [Adelheid-XT Keyboard created by dcpedit](https://github.com/dcpedit/adelheid-xt). I submitted a PR of those changes back up to @dcpedit, but for whatever reason, they took steps that removed my code from [their fork](https://github.com/dcpedit/vial-qmk) of [the official vial-qmk repo](https://github.com/vial-kb/vial-qmk). I guess they didn't want to own my code, which is fair, but I wish they had chosen to reject my PR and/or asked me to commit to upstream.
